Webhook'lar

Themis her ceza olayını Discord'a ya da kendi sunucunuza gönderebilir. İki biçim vardır: DISCORD zengin bir embed atar, THEMIS imzalı JSON gönderir.

Tanım

webhooks:
  - name: discord-log
    enabled: true
    url: "https://discord.com/api/webhooks/..."
    format: DISCORD
    events: ["punishment.issued", "punishment.revoked"]
    types: []                 # boş = hepsi; ya da ban, mute, warn, kick, note
    include-silent: false
  - name: my-backend
    enabled: true
    url: "https://example.com/themis-webhook"
    format: THEMIS
    secret: "uzun-rastgele-bir-değer"
    events: ["*"]
    types: []
    include-silent: true
    expose-ips: false
ALANAÇIKLAMA
eventspunishment.issued, punishment.revoked, punishment.edited, punishment.expired ya da *.
typesYalnızca bu ceza türleri; boşsa hepsi.
include-silentSessiz cezalar da gönderilsin mi.
secretTHEMIS biçiminde imza anahtarı.
expose-ipsYükte tam IP'ler; kapalıyken maskelidir.

Deneme: /themis webhook test açık webhook'lara örnek bir ban olayı gönderir.

Başlıklar: X-Themis-Event, X-Themis-Delivery (teslimat kimliği), X-Themis-Signature.

İmzayı doğrulama

X-Themis-Signature: t=<unix>,v1=<hex>, burada v1 = HMAC_SHA256(secret, t + "." + ham_gövde). Beş dakikadan eski teslimatları reddedin.

// Node.js
const crypto = require('node:crypto');
function verify(rawBody, header, secret) {
  const { t, v1 } = Object.fromEntries(header.split(',').map(p => p.split('=')));
  if (Math.abs(Date.now() / 1000 - Number(t)) > 300) return false;
  const want = crypto.createHmac('sha256', secret).update(t + '.' + rawBody).digest('hex');
  return want.length === v1.length && crypto.timingSafeEqual(Buffer.from(want), Buffer.from(v1));
}

Yeniden deneme

Ağ hatası, 429 ya da 5xx yanıtında teslimat 2, 4, 8 ve 16 saniye arayla toplam beş kez denenir. Diğer yanıtlar tekrar denenmez; sonuç konsola yazılır.
