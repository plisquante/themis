REST API

Paneller, Discord botları ve siteler Themis'e HTTP ile bağlanır. API, OpenAPI 3.1 ile tanımlı 17 uç noktadan oluşur.

Açma

rest-api:
  enabled: true
  bind: "127.0.0.1"
  port: 8787

/themis reload sonrası API http://127.0.0.1:8787/v1 adresinde dinler. Dışarıya açacaksanız önüne HTTPS'li bir ters vekil (nginx, Caddy) koyun.

Anahtarlar ve kapsamlar

/themis token create panel read,write,stream
/themis token list
/themis token revoke panel

Anahtar thm_ ile başlar ve yalnızca bir kez gösterilir; Themis yalnızca SHA-256 özetini saklar.

KAPSAMİZİN
readCezaları, oyuncuları, şablonları ve istatistikleri okuma.
writeCeza verme, düzenleme, kaldırma, şablon uygulama.
streamCanlı olay akışı.
adminHepsi + IP geçmişi; expose-ips: true ise tam IP'ler.

Anahtarı Authorization: Bearer thm_… ya da X-Themis-Token: thm_… başlığıyla gönderin.

Uç noktalar

YÖNTEMYOLKAPSAMNE YAPAR
GET/v1/health—Çalışıyor mu, sürüm. Anahtar gerekmez.
GET/v1/openapi.json—OpenAPI 3.1 sözleşmesi. Anahtar gerekmez.
GET/v1/whoamiherhangiAnahtarın adı ve kapsamları.
GET/v1/statsreadTür başına etkin, son 24 saat, son 7 gün ve toplam sayılar.
GET/v1/streamstreamAğdaki her ceza değişikliğinin canlı akışı (Server-Sent Events).
GET/v1/punishmentsreadCeza arama.
POST/v1/punishmentswriteCeza verme.
GET/v1/punishments/{ref}readTek ceza ve kanıtı (evidence); {ref} sayısal kimlik ya da dosya kodu.
PATCH/v1/punishments/{ref}writeSebep, süre/bitiş ya da metadata düzenleme.
DELETE/v1/punishments/{ref}writeKaldırma.
POST/v1/punishments/{ref}/revokewriteSebeple kaldırma.
GET/v1/players/{ref}readProfil, etkin ban/mute ve sayılar; {ref} ad ya da UUID.
GET/v1/players/{ref}/punishmentsreadOyuncunun sicili; /punishments filtrelerini alır.
GET/v1/players/{ref}/altsreadAynı IP'yi paylaşan hesaplar.
GET/v1/players/{ref}/ipsadminIP geçmişi.
GET/v1/templatesreadCeza şablonları.
POST/v1/templates/{key}/applywriteŞablonun sıradaki basamağını uygulama.

Arama filtreleri: target, ip, issuer, type (virgüllü: ban,mute), status (active,expired,revoked), template, search, since, until (ISO-8601 ya da unix saniye), limit, offset, order.

Örnekler

# oyuncu
curl -H "Authorization: Bearer thm_…" http://127.0.0.1:8787/v1/players/Steve

# ceza ver (aynı Idempotency-Key ile tekrar gönderilirse ikinci ceza oluşmaz)
curl -X POST http://127.0.0.1:8787/v1/punishments \
  -H "Authorization: Bearer thm_…" -H "Content-Type: application/json" \
  -H "Idempotency-Key: ticket-4411" \
  -d '{"type":"ban","target":{"name":"Steve"},"duration":"7d","reason":"X-ray","issuer":"Website"}'

# sebeple kaldır
curl -X POST http://127.0.0.1:8787/v1/punishments/7KQ2MX/revoke \
  -H "Authorization: Bearer thm_…" -H "Content-Type: application/json" \
  -d '{"reason":"İtiraz kabul edildi","issuer":"Destek"}'

# canlı akış
curl -N -H "Authorization: Bearer thm_…" http://127.0.0.1:8787/v1/stream

Ceza gövdesi: type (zorunlu), target (uuid, name ya da ip; ip_based), reason, duration ("7d", saniye sayısı ya da kalıcı için null/"perm"), silent, shadow (yalnızca mute: gölge susturma), replace, scope, issuer, metadata.

Tek ceza yanıtında evidence dizisi, oyuncunun ceza anından önce yazdıklarını eskiden yeniye verir: {"at": "…", "server": "survival", "kind": "chat", "content": "…"}. Her cezada shadow alanı gölge susturmayı gösterir.

Yanıt biçimi ve hatalar

{ "data": { … } }
{ "error": { "code": "player_not_found", "message": "Player 'Steve' has never joined this network" } }
HTTPKODANLAMI
400invalid_request, invalid_json, invalid_type, invalid_status, invalid_durationİstek hatalı.
401unauthorizedAnahtar yok ya da geçersiz.
403insufficient_scope, target_exempt, deniedKapsam yetmiyor, hedef muaf ya da bir eklenti reddetti.
404not_found, punishment_not_found, player_not_found, template_not_foundBulunamadı.
409already_punished, not_active, cancelledZaten etkin bir ceza var (error.existing içinde), ceza etkin değil ya da bir eklenti iptal etti.
413payload_too_largeGövde 64 KiB'tan büyük.
422no_known_ipIP cezası için oyuncunun kayıtlı IP'si yok.
429rate_limitedDakikalık sınır aşıldı; Retry-After başlığına bakın.
500internal_errorSunucu hatası.

Hız sınırı, idempotency, CORS

  • Her anahtar dakikada requests-per-minute istek yapabilir. Yanıtlarda X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset vardır.
  • POST isteklerinde Idempotency-Key başlığı 24 saat boyunca aynı yanıtı döndürür; ağ hatasında güvenle tekrar deneyin.
  • Tarayıcıdan çağırmak için siteyi cors-origins listesine ekleyin.

Canlı olay akışı

/v1/stream bir Server-Sent Events bağlantısıdır. Her olay şöyle gelir; 15 saniyede bir : ping satırı bağlantıyı açık tutar:

event: punishment.issued
id: 42-0
data: {"type":"punishment.issued","created_at":"2026-11-05T19:00:00Z","remote":false,"punishment":{…}}

Olay türleri: punishment.issued, punishment.revoked, punishment.edited, punishment.expired. remote: true, olayın ağdaki başka bir sunucudan geldiğini söyler.
