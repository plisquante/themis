Java API

Themis'in API'si MIT lisanslıdır ve hiçbir sunucu yazılımına bağlı değildir: aynı kod Paper, Velocity ve BungeeCord eklentilerinde çalışır.

Projeye ekleme

API jar'ı (themis-api-<sürüm>.jar) eklentiyle birlikte indirme sayfasında gelir. Projenize koyup derleme zamanına ekleyin; çalışırken sınıflar Themis'in kendisinden gelir.

// build.gradle.kts
dependencies {
    compileOnly(files("libs/themis-api-1.0.0.jar"))
}

Eklentinizin Themis'ten sonra yüklenmesi için bağımlılık ekleyin:

PLATFORMNEREYE
Paperplugin.yml: depend: [Themis] (ya da softdepend)
Velocity@Plugin(dependencies = @Dependency(id = "themis"))
BungeeCordbungee.yml: depends: [Themis]

Erişim

ThemisApi themis = Themis.api();            // Themis yoksa IllegalStateException
Optional<ThemisApi> maybe = Themis.find();  // isteğe bağlı entegrasyon için

Paper'da aynı nesne Bukkit ServicesManager üzerinden de alınabilir (ThemisApi.class).

Ceza verme

themis.punishments().issue(PunishmentRequest.builder(PunishmentType.MUTE)
        .target(Target.player(uuid, "Steve"))
        .issuer(Actor.plugin("MyAntiSpam"))
        .duration(Duration.ofMinutes(10))
        .reason("Chat flood")
        .meta("detector", "flood-v2")
        .shadow(false)              // true: gölge susturma
        .build())
    .thenAccept(result -> {
        if (result.success()) logger.info("Dosya #" + result.punishment().code());
    });

Sonucun durumu SUCCESS, ALREADY_PUNISHED, EXEMPT, CANCELLED, DENIED ya da FAILED olur. Diğer işlemler: revoke, revokeActive, revokeActiveIp, edit, byId, byCode, query, count, activeBan, activeMute, veritabanına gitmeyen cachedMute ve cezanın kanıtını veren evidence(id). Gölge susturmayı punishment.shadow() söyler. Oyuncu bilgisi için players(): byUuid, byName, ipHistory, playersOnIp, alts.

Olaylar

// Kaydedilmeden önce engelle ya da değiştir
themis.events().subscribe(this, PunishmentIssueEvent.class, e -> {
    if (e.request().reason().isBlank()) e.cancel("Sebep zorunlu");
});

// Ağdaki her cezaya tepki ver (e.remote(): başka sunucudan geldi)
themis.events().subscribe(this, PunishmentIssuedEvent.class, EventPriority.MONITOR, e -> post(e.punishment()));

// Kapanırken
themis.events().unsubscribeAll(this);
OLAYNE ZAMAN
PunishmentIssueEventKaydedilmeden önce. İptal edilebilir; request(…) ile değiştirilebilir.
PunishmentIssuedEventKaydedildikten sonra.
PunishmentRevokeEventKaldırılmadan önce. İptal edilebilir.
PunishmentRevokedEventKaldırıldıktan sonra.
PunishmentEditedEventDüzenlendikten sonra.
PunishmentExpiredEventSüresi dolunca.
PlayerBlockedEventGiriş, sohbet ya da komut engellendiğinde.
AltJoinEventCezalı bir hesapla IP paylaşan biri girdiğinde.
İŞ PARÇACIKLARIFuture'lar ve olaylar Themis'in arka plan iş parçacıklarında çalışır. Paper'da oyuncuya ya da dünyaya dokunmadan önce ana iş parçacığına geçin (Bukkit.getScheduler().runTask(…)).

Kanıt

themis.punishments().evidence(punishment.id()).thenAccept(lines -> lines.forEach(e ->
        logger.info(e.at() + " [" + e.server() + "] " + e.content())));

Sorgu

themis.punishments().query(PunishmentQuery.builder()
        .target(uuid).types(PunishmentType.BAN, PunishmentType.MUTE).activeOnly().limit(20).build())
    .thenAccept(list -> list.forEach(p -> logger.info(p.code() + " " + p.reason())));
